Sync

Your library is saved in snippets.json in your GitHub repo, so it is permanent and shared across machines. Changes are committed automatically when a token is set on this browser.

Set up a token (once per browser)

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → this repo.
  3. Permissions → Repository → Contents: Read and write.
  4. Paste the token here and save.

The token stays in this browser only. Anyone using this browser can edit your repo, so don't save it on shared computers.

Without a token the site only reads the published snippets.json (read-only). Each commit triggers a Cloudflare Pages rebuild, so the published copy lags by about a minute.
