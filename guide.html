Using snippets in eLearn

  1. Find a snippet in the Library and click Copy HTML.
  2. In Moodle's editor, switch to the code view (</> button).
  3. Paste, then switch back and check it displays correctly.

What Moodle usually strips

  • <script>, <style>, <link>, <meta>
  • Inline event handlers such as onclick and javascript: links
  • Forms and <object>/<embed>

Safe approach

  • Use inline style="…" and theme (Bootstrap) classes.
  • Use <details> for expandable content instead of JavaScript.
  • Always include alt text on images.

About this site

Snippets are saved in this browser (localStorage). Use Export JSON on the Library page to back up or move them to another computer. The preview loads Bootstrap 4 from a CDN to approximate Moodle's look, so your theme may differ; always confirm in eLearn.
